# 💳 Credit Card Fraud Risk Analysis Dashboard

## 📌 Project Overview
This Power BI dashboard is designed to analyze credit card fraud transactions and identify risk patterns. The dashboard provides insights into fraudulent activities, risk levels, fraud trends, and geographic distribution to support data-driven decision-making.

## 🎯 Objectives
- Monitor fraudulent transactions.
- Identify high-risk and critical-risk activities.
- Analyze fraud trends over time.
- Track fraud distribution across different states.
- Understand the most common fraud types.

## 📊 Dashboard Features
- Total Fraudulent Transactions
- Fraud Rate Analysis
- Critical Risk Transactions
- Fraudulent Transaction Amount
- Fraud Type Analysis
- State-wise Fraud Distribution
- Monthly Fraud Trend Analysis
- Interactive Filters and Slicers

## 🛠️ Tools & Technologies Used
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation

## 📈 Key Insights
- Identified the most common fraud types.
- Analyzed fraud trends by month.
- Detected high-risk transaction categories.
- Evaluated state-wise fraud patterns.
- Monitored overall fraud rates and losses.

## 🚀 Business Impact
This dashboard helps financial institutions and analysts:
- Detect fraud patterns quickly.
- Monitor high-risk transactions.
- Reduce financial losses.
- Improve fraud prevention strategies.
- Support better decision-making through data insights.
